Sound Resources Placeholder
==========================

This directory should contain the following sound files for the HayiDev++ app:

1. sound_notification.mp3 - Notification sound
2. sound_message.mp3 - Message received sound
3. sound_gift.mp3 - Gift received sound
4. sound_like.mp3 - Like received sound
5. sound_call_incoming.mp3 - Incoming call ringtone
6. sound_call_end.mp3 - Call ended sound

Instructions:
- Replace this README with actual .mp3 files
- File names must be lowercase with underscores (no spaces or special characters)
- Android raw resources cannot have extensions in resource names
- Reference sounds in code using: R.raw.sound_notification (without .mp3)
- Recommended format: MP3, 44.1kHz, mono or stereo
- Keep file sizes small for fast loading (under 1MB each)
